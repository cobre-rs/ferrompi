1//! # ferrompi
2//!
3//! Safe, generic Rust bindings for MPI (Message Passing Interface).
4//!
5//! This crate wraps MPI functionality through a thin C layer.
6//!
7//! ## Capabilities
8//!
9//! - **Generic API**: All operations work with any [`MpiDatatype`] (`f32`, `f64`, `i32`, `i64`, `u8`, `u32`, `u64`)
10//! - **Blocking collectives**: barrier, broadcast, reduce, allreduce, gather, scatter, allgather,
11//!   alltoall, scan, exscan, reduce\_scatter\_block, plus V-variants (gatherv, scatterv, allgatherv, alltoallv)
12//! - **Nonblocking collectives**: All 15 `i`-prefixed variants with [`Request`] handles
13//! - **Persistent collectives** (MPI 4.0, or Open MPI 5): `*_init` forms of every blocking collective except
14//!   `barrier`, plus five in-place forms, with [`PersistentRequest`] handles
15//! - **Large counts**: with an MPI 4.0 library, a count above `i32::MAX` uses MPI's `_c` call
16//!   (point-to-point, collectives including persistent ones, RMA); below
17//!   MPI 4.0 it returns [`Error::Mpi`] with class [`MpiErrorClass::Count`]. The V-collectives
18//!   (`gatherv`, `scatterv`, `allgatherv`, `alltoallv`, and their persistent forms), which take
19//!   counts as `i32` arrays, and `allreduce_with_op`, whose user function takes an `int` length,
20//!   return that error on every MPI version.
21//! - **Scalar and in-place variants**: `reduce_scalar`, `allreduce_scalar`, `reduce_inplace`,
22//!   `allreduce_inplace`, `scan_scalar`, `exscan_scalar`
23//! - **Point-to-point**: `send`, `recv`, `isend`, `irecv`, `sendrecv`, `probe`, `iprobe`
24//! - **Persistent point-to-point**: `send_init`, `bsend_init`, `rsend_init`, `ssend_init`,
25//!   `recv_init` methods on [`Communicator`], each returning a [`PersistentRequest`]
26//! - **Communicator management**: `split`, `split_type`, `split_shared`, `duplicate`
27//! - **Group operations**: [`Group`] with incl/excl/union/intersection/difference,
28//!   [`RankRange`] for range constructors, [`GroupComparison`].
29//!
30//!   Note: [`Mpi::create_from_group`] needs MPI 4.0, or Open MPI 5.
31//! - **Custom datatypes**: [`CustomDatatype`]
32//!   (contiguous/vector/struct/resized) and [`StructField`]
33//!   for struct-type builders.
34//! - **User-defined reduction operations**: [`UserOp`] wraps `MPI_Op_create`
35//!   with safe closure storage and trampoline.
36//! - **Distributed RMA windows** (feature `rma`): `Win<T>` with
37//!   `WinFenceAssert`, `WinPscwAssert`,
38//!   `WinLockGuard`, and `WinLockAllGuard`
39//!   RAII guards.
40//! - **Shared memory windows** (feature `rma`): `SharedWindow<T>`
41//!   with RAII lock guards for intra-node shared memory (distinct from the
42//!   distributed `Win<T>` windows above).
43//! - **Info objects**: [`Info`] creates and queries MPI info objects;
44//!   no ferrompi call takes one yet.
45//! - **SLURM helpers** (feature `numa`): Job topology queries via `slurm` module
46//! - **Rich error handling**: [`MpiErrorClass`] categorization with messages from the MPI runtime
47//!
48//! ## Supported Types
49//!
50//! All communication operations are generic over [`MpiDatatype`]:
51//! `f32`, `f64`, `i32`, `i64`, `u8`, `u32`, `u64`
52//!
53//! ## Quick Start
54//!
55//! ```no_run
56//! use ferrompi::{Mpi, ReduceOp};
57//!
58//! fn main() -> Result<(), ferrompi::Error> {
59//!     let mpi = Mpi::init()?;
60//!     let world = mpi.world();
61//!
62//!     let rank = world.rank();
63//!     let size = world.size();
64//!     println!("Hello from rank {} of {}", rank, size);
65//!
66//!     // Generic broadcast — works with any MpiDatatype
67//!     let mut data = vec![0.0f64; 100];
68//!     if rank == 0 {
69//!         data.fill(42.0);
70//!     }
71//!     world.broadcast(&mut data, 0)?;
72//!
73//!     // Generic all-reduce
74//!     let sum = world.allreduce_scalar(rank as f64, ReduceOp::Sum)?;
75//!     println!("Rank {rank}: sum of all ranks = {sum}");
76//!
77//!     Ok(())
78//! }
79//! ```
80//!
81//! ## Feature Flags
82//!
83//! | Feature | Description | Dependencies |
84//! |---------|-------------|--------------|
85//! | `rma`   | RMA and shared-memory windows (`Win`, `SharedWindow`, lock guards, RMA operations, `ReduceOp::Replace`/`NoOp`) | — |
86//! | `numa`  | The `slurm` module and `SlurmInfo` | `rma` |
87//!
88//! `numa` needs no system library: it implies `rma` and adds only the SLURM
89//! job-topology helpers; it adds no NUMA code.
90//!
91//! ## Thread Safety
92//!
93//! [`Communicator`], [`Group`], [`Request`], [`PersistentRequest`], [`Status`],
94//! [`CustomDatatype`], [`Info`], and [`UserOp`] are `Send + Sync`; [`Mpi`],
95//! `Win<T>`, `SharedWindow<T>` (feature `rma`), and their RAII lock guards are not.
96//!
97//! Which thread may call MPI is set by the provided [`ThreadLevel`]; see its
98//! documentation for the per-level rules.
99//!
100//! ## Hybrid MPI+OpenMP
101//!
102//! For hybrid parallelism, use [`Mpi::init_thread()`] with the appropriate level:
103//!
104//! - **[`Funneled`](ThreadLevel::Funneled)** (recommended): Only the main thread makes MPI calls.
105//!   OpenMP threads handle computation between MPI calls.
106//! - **[`Serialized`](ThreadLevel::Serialized)**: Any thread can make MPI calls, but only one at a time.
107//! - **[`Multiple`](ThreadLevel::Multiple)**: Full concurrent MPI from any thread (highest overhead).
108//!
109//! ```no_run
110//! use ferrompi::{Mpi, ThreadLevel, ReduceOp};
111//!
112//! // Request funneled support for hybrid MPI + threads
113//! let mpi = Mpi::init_thread(ThreadLevel::Funneled).unwrap();
114//! assert!(mpi.thread_level() >= ThreadLevel::Funneled);
115//!
116//! let world = mpi.world();
117//! // Worker threads compute locally, main thread calls MPI
118//! let local = 42.0_f64;
119//! let global = world.allreduce_scalar(local, ReduceOp::Sum).unwrap();
120//! ```
121//!
122//! ### SLURM Configuration
123//!
124//! ```bash
125//! #SBATCH --ntasks-per-node=4        # MPI ranks per node
126//! #SBATCH --cpus-per-task=8          # OpenMP threads per rank
127//! export OMP_NUM_THREADS=$SLURM_CPUS_PER_TASK
128//! srun --cpu-bind=cores ./my_program
129//! ```
130//!
131//! Use the `slurm` module (with `numa` feature) to read these values at runtime.
132//! See `examples/hybrid_openmp.rs` for the full pattern.
133//!
134//! ## Lifecycle
135//!
136//! Dropping the [`Mpi`] handle finalizes MPI. See [`Mpi`] for what happens to
137//! other handles afterwards, and [`Error`] for which failures return `Err`
138//! and which abort the process.
139//!
140//! ## Extended documentation
141//!
142//! The [`doc`] module embeds the long-form guides and the architecture
143//! decision records.

213/// Process-wide buffer attached for buffered sends (`MPI_Buffer_attach`).
214///
215/// MPI allows at most one attached buffer per process. This static holds the
216/// `Box<[u8]>` so that the allocation remains valid for the duration of the
217/// attachment. The `Mutex` is held only briefly during `buffer_attach` and
218/// `buffer_detach` transitions; MPI itself manages the buffer between those
219/// two calls.
220static ATTACHED_BUFFER: Mutex<Option<Box<[u8]>>> = Mutex::new(None);

222/// MPI thread support levels.
223///
224/// | Level | Who may call MPI | Synchronization |
225/// |-------|-------------------|------------------|
226/// | [`Single`](ThreadLevel::Single) | Only the thread that called [`Mpi::init_thread`] | N/A |
227/// | [`Funneled`](ThreadLevel::Funneled) | Only the thread that called [`Mpi::init_thread`] | N/A |
228/// | [`Serialized`](ThreadLevel::Serialized) | Any thread | Caller serializes; debug builds detect an overlap |
229/// | [`Multiple`](ThreadLevel::Multiple) | Any thread | None needed |
230///
231/// A call from any other thread at [`Single`](ThreadLevel::Single) or
232/// [`Funneled`](ThreadLevel::Funneled) returns
233/// `Err(`[`Error::ThreadLevelViolation`]`)` without calling MPI. At
234/// [`Serialized`](ThreadLevel::Serialized), the caller must serialize its own
235/// calls; a debug build that detects two calls overlapping also returns that
236/// error (a consuming [`Request::wait`](crate::Request::wait) aborts the
237/// process instead), but a release build does not check.
238///
239/// [`Mpi::thread_level()`] reports the level MPI actually granted, which may
240/// be lower than the level requested to [`Mpi::init_thread`]; it is the
241/// granted level, not the requested one, that these rules apply to.
242#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
243#[repr(i32)]
244pub enum ThreadLevel {
245    /// Only single-threaded execution
246    Single = 0,
247    /// Multi-threaded, but MPI calls only from main thread
248    Funneled = 1,
249    /// Multi-threaded, but MPI calls serialized by user
250    Serialized = 2,
251    /// Full multi-threaded support
252    Multiple = 3,
253}

255/// MPI environment handle.
256///
257/// # Lifecycle
258///
259/// There is one `Mpi` per process. While a handle is alive,
260/// [`Mpi::init`]/[`Mpi::init_thread`] return
261/// `Err(`[`Error::AlreadyInitialized`]`)`; once it is dropped, they return
262/// `Err(`[`Error::Finalized`]`)`. MPI cannot be re-initialized.
263///
264/// Dropping this handle finalizes MPI. Afterward, every method that calls
265/// MPI through a communicator, group, request, window, datatype, info or
266/// user op returns `Err(`[`Error::Finalized`]`)` without calling MPI. The
267/// queries the MPI standard allows at any time ([`Mpi::version`],
268/// [`Mpi::library_version`], [`Mpi::is_initialized`],
269/// [`Mpi::is_finalized`]) still answer. A communicator, request, window or
270/// window lock guard, datatype, group, info object or user op that outlives
271/// this handle makes no MPI call when it is dropped.
272///
273/// If any window (feature `rma`) is still alive when this handle is
274/// dropped — whatever constructed it — `MPI_Finalize` is skipped instead,
275/// with a stderr warning, because some MPI implementations free
276/// MPI-allocated window memory inside `MPI_Finalize` itself, and some abort
277/// while tearing down internal state that still tracks a live window;
278/// window memory stays valid until the process exits. Launchers can report
279/// such an exit differently from a clean one; see
280/// [`doc::mpi_compatibility`]. Debug builds print a note to stderr when
281/// finalize still leaves MPI requests unfreed.
282///
283/// At [`ThreadLevel::Single`]/[`ThreadLevel::Funneled`], dropping a handle
284/// whose `Drop` calls MPI — an uncompleted [`Request`], a
285/// [`PersistentRequest`], a communicator other than the world, a window or
286/// window lock guard, a datatype, group, info object or user op — on a
287/// thread other than the one that called [`Mpi::init`]/[`Mpi::init_thread`]
288/// prints
289/// `ferrompi: <Type> dropped on thread <name or id>` to stderr and aborts
290/// the process.
291///
292/// At [`ThreadLevel::Serialized`]/[`ThreadLevel::Multiple`], dropping this
293/// handle while another thread is still inside an MPI call through this
294/// crate is a program error that `ferrompi` does not detect.
295///
296/// A call that would fail one of the checks above (finalized, wrong
297/// thread) and is also given invalid arguments may return the argument
298/// error (for example [`Error::InvalidBuffer`]) instead of
299/// `Err(`[`Error::Finalized`]`)`/`Err(`[`Error::ThreadLevelViolation`]`)`;
300/// the order in which these checks run is not part of the API.
301///
302/// # Example
303///
304/// ```no_run
305/// use ferrompi::Mpi;
306///
307/// let mpi = Mpi::init().expect("Failed to initialize MPI");
308/// let world = mpi.world();
309/// println!("Running on {} processes", world.size());
310/// // MPI is finalized when `mpi` goes out of scope
311/// ```
312pub struct Mpi {
313    /// The thread level that was provided
314    thread_level: ThreadLevel,
315    /// Marker to make Mpi !Send and !Sync
316    _marker: PhantomData<*const ()>,
317}

319impl Mpi {
320    /// Initialize MPI with single-threaded support.
321    ///
322    /// # Errors
323    ///
324    /// Returns `Err(`[`Error::AlreadyInitialized`]`)` while an `Mpi` handle
325    /// exists or another thread is initializing, `Err(`[`Error::Finalized`]`)`
326    /// once MPI has been finalized, or `Err(`[`Error::Mpi`]`)` if
327    /// `MPI_Init_thread` itself fails. An error inside `MPI_Init_thread`
328    /// itself usually aborts the process before `Err(`[`Error::Mpi`]`)` can
329    /// be returned; see [`Error`].
330    pub fn init() -> Result<Self> {
331        Self::init_thread(ThreadLevel::Single)
332    }
333
334    /// Initialize MPI with the specified thread support level.
335    ///
336    /// # Arguments
337    ///
338    /// * `required` - The minimum thread support level required
339    ///
340    /// # Returns
341    ///
342    /// Returns the MPI handle. The actual thread support level provided can be
343    /// queried with [`thread_level()`](Self::thread_level).
344    ///
345    /// # Errors
346    ///
347    /// Returns `Err(`[`Error::AlreadyInitialized`]`)` while an `Mpi` handle
348    /// exists or another thread is initializing, `Err(`[`Error::Finalized`]`)`
349    /// once MPI has been finalized, or `Err(`[`Error::Mpi`]`)` if
350    /// `MPI_Init_thread` itself fails. An error inside `MPI_Init_thread`
351    /// itself usually aborts the process before `Err(`[`Error::Mpi`]`)` can
352    /// be returned; see [`Error`].
353    pub fn init_thread(required: ThreadLevel) -> Result<Self> {
354        rt::begin_init()?;
355
356        let mut already_finalized: i32 = 0;
357        // SAFETY: already_finalized is a local out-parameter that
358        // ferrompi_finalized writes before this reads it below;
359        // ferrompi_finalized is legal to call at any point in the process
360        // lifecycle, including before MPI_Init_thread.
361        unsafe { ffi::ferrompi_finalized(&mut already_finalized) };
362        if already_finalized != 0 {
363            rt::abandon_init();
364            return Err(Error::Finalized);
365        }
366
367        let mut provided: i32 = 0;
368        // SAFETY: provided is a local out-parameter written by MPI_Init_thread;
369        // rt::begin_init's compare-exchange above guarantees this is the only
370        // MPI_Init_thread call in the process at a time, and the finalized
371        // check above guarantees MPI has not already been finalized.
372        let ret = unsafe { ffi::ferrompi_init_thread(required as i32, &mut provided) };
373
374        if ret != 0 {
375            rt::abandon_init();
376            return Err(Error::Mpi {
377                class: MpiErrorClass::Raw(ret),
378                code: ret,
379                message: format!("MPI_Init_thread failed with code {ret}"),
380                operation: Some("init_thread"),
381            });
382        }
383
384        let thread_level = match provided {
385            0 => ThreadLevel::Single,
386            1 => ThreadLevel::Funneled,
387            2 => ThreadLevel::Serialized,
388            _ => ThreadLevel::Multiple,
389        };
390
391        rt::activate(thread_level);
392
393        Ok(Mpi {
394            thread_level,
395            _marker: PhantomData,
396        })
397    }

409    /// Get the current wall-clock time (`MPI_Wtime`), in seconds.
410    ///
411    /// This is a high-resolution timer suitable for benchmarking. It takes
412    /// `&self` because MPI must be initialized and not yet finalized; code
413    /// without the handle can use [`std::time::Instant`].
414    pub fn wtime(&self) -> f64 {
415        // SAFETY: ferrompi_wtime takes no pointer arguments and touches no
416        // Rust-owned memory; `&self` proves MPI is initialized and not
417        // finalized, and `Mpi` is neither `Send` nor `Sync`, so this runs on
418        // the thread that initialized MPI.
419        unsafe { ffi::ferrompi_wtime() }
420    }

422    /// Get the MPI library version string (implementation-specific).
423    ///
424    /// Returns a string such as `"Open MPI v4.1.6"` or `"Intel(R) MPI Library 2021.7"`.
425    /// This wraps `MPI_Get_library_version`.
426    /// The string ends before the first NUL character, with trailing whitespace removed.
427    pub fn library_version() -> Result<String> {
428        let mut buf = [0u8; 8192];
429        let mut len: i32 = 0;
430        // SAFETY: buf is a local 8192-byte buffer; MPI writes at most
431        // MPI_MAX_LIBRARY_VERSION_STRING bytes, which the C layer asserts at build time
432        // is at most 8192, and reports the length through the local `len`.
433        let ret = unsafe {
434            ffi::ferrompi_get_library_version(buf.as_mut_ptr().cast::<c_char>(), &mut len)
435        };
436        Error::check_with_op(ret, "get_library_version")?;
437        let len = (len.max(0) as usize).min(buf.len());
438        // Open MPI counts the terminating NUL in `len`; some implementations
439        // append trailing whitespace.
440        let len = buf[..len].iter().position(|&b| b == 0).unwrap_or(len);
441        let s = std::str::from_utf8(&buf[..len])
442            .map_err(|_| Error::Internal("Invalid UTF-8 in library version string".into()))?;
443        Ok(s.trim_end().to_string())
444    }

446    /// Get the MPI standard version string (e.g., "MPI 4.0").
447    pub fn version() -> Result<String> {
448        let mut buf = [0u8; 256];
449        let mut len: i32 = 0;
450        // SAFETY: buf is a local 256-byte buffer, large enough for an MPI
451        // version string ("MPI x.y"); the C layer writes at most buf.len()
452        // bytes into it and reports the written length through `len`.
453        let ret = unsafe { ffi::ferrompi_get_version(buf.as_mut_ptr().cast::<c_char>(), &mut len) };
454        Error::check_with_op(ret, "get_version")?;
455
456        let len = (len.max(0) as usize).min(buf.len());
457        let s = std::str::from_utf8(&buf[..len])
458            .map_err(|_| Error::Internal("Invalid UTF-8 in version string".into()))?;
459        Ok(s.to_string())
460    }

472    ///
473    /// Returns `true` once the `Mpi` handle has been dropped, including when

486    /// Create a communicator from a group without requiring a parent
487    /// communicator (MPI 4.0, or Open MPI 5).
488    ///
489    /// `stringtag` must be identical across all ranks that participate
490    /// in the call; ranks with different tags or in different groups
491    /// produce separate communicators.
492    ///
493    /// # Errors
494    ///
495    /// - Returns `Err(Error::Internal(_))` if `stringtag` contains a null byte
496    ///   (the FFI call is never invoked in this case).
497    /// - Returns `Err(Error::NotSupported(_))` when ferrompi was built
498    ///   against an MPI older than 4.0 other than Open MPI 5.
499    /// - Returns `Err(Error::Mpi { .. })` if the underlying MPI call fails.
500    ///
501    /// # Example
502    ///
503    /// ```no_run
504    /// use ferrompi::Mpi;
505    ///
506    /// let mpi = Mpi::init().unwrap();
507    /// let world = mpi.world();
508    /// let g = world.group().unwrap();
509    /// // All ranks participate with the same tag.
510    /// let comm = mpi.create_from_group(&g, "my-tag").unwrap();
511    /// assert_eq!(comm.size(), world.size());
512    /// ```
513    pub fn create_from_group(&self, group: &group::Group, stringtag: &str) -> Result<Communicator> {
514        let c_tag = CString::new(stringtag)
515            .map_err(|_| Error::Internal("stringtag contains null byte".into()))?;
516        let mut new_handle: i32 = -1;
517        // SAFETY: c_tag.as_ptr() is a valid, null-terminated C string that
518        // lives for the duration of this call. group.handle is a valid group
519        // handle obtained from ferrompi_comm_group or a group-constructor shim.
520        // &mut new_handle is a pointer to a stack-allocated i32.
521        let ret = unsafe {
522            ffi::ferrompi_comm_create_from_group(group.handle, c_tag.as_ptr(), &mut new_handle)
523        };
524        Error::check_with_op(ret, "comm_create_from_group")?;
525        Communicator::from_handle(new_handle)
526    }

528    /// Attach a user-provided buffer for use by buffered sends.
529    ///
530    /// This wraps `MPI_Buffer_attach`. Once attached, the buffer is owned by
531    /// MPI until [`buffer_detach`](Self::buffer_detach) is called. Only one
532    /// buffer may be attached per process at a time; attempting to attach a
533    /// second buffer without first detaching returns
534    /// `Err(`[`Error::InvalidOp`]`)`.
535    ///
536    /// The `buffer` is stored in a process-wide static so its allocation
537    /// remains valid for the lifetime of the attachment. You must not access
538    /// the raw bytes of `buffer` between `buffer_attach` and `buffer_detach` —
539    /// MPI owns the contents during that window.
540    ///
541    /// # Buffer Sizing
542    ///
543    /// The recommended buffer size for `N` buffered sends of `count` elements
544    /// of type `T` is:
545    ///
546    /// ```text
547    /// N * (MPI_BSEND_OVERHEAD + count * size_of::<T>())
548    /// ```
549    ///
550    /// `MPI_BSEND_OVERHEAD` is implementation-specific; use at least a few
551    /// hundred extra bytes per buffered send. For safety, use a generous margin.
552    ///
553    /// Buffers larger than `i32::MAX` bytes are rejected with
554    /// `Err(`[`Error::InvalidBuffer`]`)` before the FFI call; the
555    /// underlying `MPI_Buffer_attach` takes an `int` count and cannot
556    /// address larger buffers.
557    ///
558    /// # Errors
559    ///
560    /// - [`Error::InvalidBuffer`] if `buffer.len() > i32::MAX as usize`.
561    /// - [`Error::InvalidOp`] if a buffer is already attached.
562    /// - [`Error::Mpi`] if `MPI_Buffer_attach` fails.
563    ///
564    /// # Example
565    ///
566    /// ```no_run
567    /// # use ferrompi::Mpi;
568    /// let mpi = Mpi::init().unwrap();
569    /// mpi.buffer_attach(vec![0u8; 64 * 1024].into_boxed_slice()).unwrap();
570    /// // ... buffered sends here ...
571    /// let _ = mpi.buffer_detach().unwrap();
572    /// ```
573    pub fn buffer_attach(&self, buffer: Box<[u8]>) -> Result<()> {
574        let mut guard = ATTACHED_BUFFER
575            .lock()
576            .map_err(|_| Error::Internal("ATTACHED_BUFFER mutex poisoned".into()))?;
577        if guard.is_some() {
578            return Err(Error::InvalidOp);
579        }
580        if buffer.len() > i32::MAX as usize {
581            return Err(Error::InvalidBuffer);
582        }
583        let ptr = buffer.as_ptr() as *mut std::ffi::c_void;
584        let size = buffer.len() as i64;
585        // Store the box in the static BEFORE calling MPI so the memory is
586        // guaranteed alive when MPI begins using the buffer.
587        *guard = Some(buffer);
588        // SAFETY: ptr points to the boxed slice we just stored in the static;
589        // the allocation remains valid until buffer_detach drops it. size is
590        // the exact byte length of that allocation.
591        let ret = unsafe { ffi::ferrompi_buffer_attach(ptr, size) };
592        if ret != 0 {
593            // Roll back: reclaim the box so the caller can retry.
594            guard.take();
595            return Err(Error::from_code_with_op(ret, "buffer_attach"));
596        }
597        Ok(())
598    }
599
600    /// Detach the previously attached buffer and return it to the caller.
601    ///
602    /// This wraps `MPI_Buffer_detach`. The call **blocks** until all buffered
603    /// sends that are currently using the buffer have completed. Once this
604    /// returns, the returned `Box<[u8]>` is owned by the caller again and
605    /// may be dropped or reused.
606    ///
607    /// Do **not** call this from a `Drop` implementation (e.g., on a wrapper
608    /// around `Mpi`). `MPI_Buffer_detach` blocks until pending sends drain;
609    /// blocking inside `Drop` can produce hard-to-diagnose hangs.
610    ///
611    /// # Errors
612    ///
613    /// - [`Error::InvalidOp`] if no buffer is currently attached.
614    /// - [`Error::Mpi`] if `MPI_Buffer_detach` fails.
615    ///
616    /// # Example
617    ///
618    /// ```no_run
619    /// # use ferrompi::Mpi;
620    /// let mpi = Mpi::init().unwrap();
621    /// mpi.buffer_attach(vec![0u8; 64 * 1024].into_boxed_slice()).unwrap();
622    /// // ... buffered sends ...
623    /// let _buf = mpi.buffer_detach().unwrap(); // dropped here
624    /// ```
625    pub fn buffer_detach(&self) -> Result<Box<[u8]>> {
626        let mut guard = ATTACHED_BUFFER
627            .lock()
628            .map_err(|_| Error::Internal("ATTACHED_BUFFER mutex poisoned".into()))?;
629        if guard.is_none() {
630            return Err(Error::InvalidOp);
631        }
632        let mut out_ptr: *mut std::ffi::c_void = std::ptr::null_mut();
633        let mut out_size: i64 = 0;
634        // SAFETY: out_ptr and out_size are valid stack-allocated output parameters.
635        // MPI_Buffer_detach writes the buffer pointer and its size into them.
636        let ret = unsafe { ffi::ferrompi_buffer_detach(&mut out_ptr, &mut out_size) };
637        if ret != 0 {
638            return Err(Error::from_code_with_op(ret, "buffer_detach"));
639        }
640        // Reclaim the Box from the static; this is the same allocation MPI just
641        // released. We take() here so the static is cleared atomically.
642        Ok(guard.take().expect("guard was Some; take() must succeed"))
643    }
644}
645
646impl Drop for Mpi {
647    fn drop(&mut self) {
648        // rt::finalize() moves the lifecycle state from Active to Finalized
649        // before ferrompi_finalize runs, so a handle whose drop is nested
650        // inside the finalize sweep (a closure captured by a request/op that
651        // the sweep drops) observes Finalized and makes no MPI call. It also
652        // returns false for a stub Mpi built without init (Uninit) and for a
653        // second call on an already-finalized state, so this branch runs
654        // ferrompi_finalize at most once.
655        if rt::finalize() {
656            #[cfg(feature = "rma")]
657            {
658                let live = window::live_windows();
659                if live > 0 {
660                    // A single write so concurrent ranks' output cannot interleave mid-line.
661                    let msg = format!(
662                        "ferrompi: MPI_Finalize skipped: {live} window(s) still alive; their memory stays valid until the process exits\n"
663                    );
664                    let _ = std::io::stderr().write_all(msg.as_bytes());
665                    return;
666                }
667            }
668            let mut active: i32 = 0;
669            // SAFETY: `active` is a valid local out-parameter that
670            // ferrompi_finalize writes the unfreed-active-request count
671            // into. rt::finalize() just returned true, so state was Active —
672            // MPI_Init(_thread) succeeded and MPI_Finalize has not yet been
673            // called for this process.
674            unsafe {
675                ffi::ferrompi_finalize(&mut active);
676            }
677            if cfg!(debug_assertions) && active > 0 {
678                // A single write so concurrent ranks' output cannot interleave mid-line.
679                let msg =
680                    format!("ferrompi: MPI_Finalize leaves {active} active request(s) unfreed\n");
681                let _ = std::io::stderr().write_all(msg.as_bytes());
682            }
683        }
684    }
685}

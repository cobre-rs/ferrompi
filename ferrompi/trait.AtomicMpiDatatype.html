Trait for types eligible for use with MPI_Compare_and_swap.

This is a sealed trait — it cannot be implemented outside this crate. MPI-4.1 §12.3.4 allows only integer, logical and byte datatypes in MPI_Compare_and_swap; of ferrompi’s element types these are i32, i64, u32, u64 and u8.

Floating-point types (f32, f64) are intentionally excluded. The MPI standard does not allow them in compare-and-swap. Accepting them would introduce silent portability bugs across MPI implementations.

This trait is used as a bound on ActiveEpoch::compare_and_swap and PassiveEpoch::compare_and_swap to ensure the method only exists for windows whose element type is CAS-eligible.

§Eligible types only

compare_and_swap exists only for integer and byte elements: on an f64 window the method is not found.

ⓘ
fn _check(e: &ferrompi::ActiveEpoch<'_, '_, f64>, v: &'static f64, r: &'static mut f64) -> ferrompi::Result<()> {
    e.compare_and_swap(v, v, r, 0, 0)
}

The same call on an i64 window compiles:

fn _check(e: &ferrompi::ActiveEpoch<'_, '_, i64>, v: &'static i64, r: &'static mut i64) -> ferrompi::Result<()> {
    e.compare_and_swap(v, v, r, 0, 0)
}

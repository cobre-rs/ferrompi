Learn MPI through Rust

The ferrompi tutorial

This tutorial teaches MPI from the beginning, using ferrompi for every example, and then explains how ferrompi brings MPI to Rust: what it hands to the MPI library, what it adds on top, and how to work on it.

It is written for developers joining the project and for anyone who wants to learn MPI through Rust. It assumes you can read Rust and use a Linux shell; it assumes no prior MPI knowledge.

Part I covers MPI itself. The concepts are the MPI standard’s, not ferrompi’s, so they carry over to C, Fortran, Julia or Python MPI code; the examples are ferrompi programs you can run. Part II covers ferrompi’s internals: the build, the C shim, the safety model, testing, and how to add a new MPI call. Its last chapter reads the communication of a real program for the patterns it is built from. Read Part I in order; each chapter of Part II stands on Part I.

The reference material this tutorial builds on is published next to it: the architecture guide for the internals, the MPI compatibility guide for building and running under each MPI library, and the architecture decision records in the documentation index for why each design was chosen. When the tutorial and one of those disagree, the reference document is right.

  1. 8Building and running: what cargo builds, which library a program loads, and launching and debugging a job

  3. 10The C shim: the interface Rust calls, the tables that hold MPI’s handles, how threads share them, and what happens when one is full
  4. 11The safety model: the scope that keeps a buffer borrowed while MPI uses it, panics, owned buffers, and the run-time states behind handles without a lifetime

Before you start

You need Rust 1.85 or newer and an MPI library with its development headers. On Ubuntu or Debian, install MPICH:

sudo apt-get install mpich libmpich-dev pkg-config
Ubuntu 24.04 ships a broken MPICH

Its mpich 4.2.0 package starts every process as a separate one-process job, so mpiexec -n 4 prints “rank 0 of 1” four times (Launchpad bug 2072338). Use an MPICH 4.2.1 or later package, as CI does (mpich-hotfix.sh lists the exact packages), build MPICH from source, or install Open MPI instead: sudo apt-get install openmpi-bin libopenmpi-dev pkg-config. Chapter 1 shows how to recognize the symptom.

ferrompi’s build script finds the MPI library through pkg-config, the mpicc compiler wrapper, or a few common install prefixes. If it finds none, or finds the wrong one, point it at a wrapper explicitly:

MPICC=/usr/bin/mpicc.mpich cargo build --examples

The MPI compatibility guide gives the full detection order and the other variables it reads.

Every example in this tutorial is either one of the programs in examples/ or a complete main you can paste into a file there. Build first, then start the built binary under the launcher:

cargo build --example hello_world
mpiexec -n 4 target/debug/examples/hello_world

Chapter 1 explains what mpiexec does and why you launch the binary rather than cargo run.

Every program here is tested

Each Rust program in the tutorial is built and run by CI under mpiexec, at the process count its label shows. Where a chapter prints a program’s output, CI compares it with a real run.
